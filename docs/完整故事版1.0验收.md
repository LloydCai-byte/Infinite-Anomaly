# 无限异常 · 完整故事版 1.0 验收

日期：2026-09-26。当前入口 `scenes/campaign/main.tscn`，剧情数据 `data/campaign.json`。

## 交付范围

这是有开场、成长循环、三章九段故事和唯一结局的可通关版本。玩法为彩色场景点击探索和能力判定；重复已知路线可自动推进，未知内容必须接手。当前完整内容边界为九个异常事件，不将远期数百事件或即时动作战斗算作已完成。

- 七个住宅视角分别切换，门、冰箱、床、电脑、手机、漫画册承担交互。
- 每个异常事件有三处发现、感知/战斗/生存三种解决方式与独立成败叙述。
- 成长共三个方向，每方向六次提升；升级前显示当前能力与行动需求。
- 首次发现给经验；成功重走旧路有经验；反复失败不重复给经验。
- 第一份经历保留，成功突破更新批注。黑白记忆只显示当前事件的两格。
- 自动重复可选择原路循环或顺序向前，遇到未知内容停下且不耗资源。
- 只有一个剧情结局。食物耗尽为 Game Over，从存档恢复。
- 初始记录、20 分钟有效游玩自动存档、床边记录、保存退出、结局记录；三个备份及校验。
- 音量、全屏、文字即时显示、减少镜头过渡、暂停、失焦暂停和键盘操作。
