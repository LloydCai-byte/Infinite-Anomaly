# 《无限异常》异常分类规范 v1.0（正式设计提案）

日期：2026-09-27。状态：待讨论定稿。本文件不改变现有游戏实现，也不将新拟定的小类冒充用户原文已有结论。

依据：用户批准的《故事背景》revision 1832，原文快照为 `docs/design-baseline-2026-09-27/原文快照.md`。原文明确六大类，提出每类约五个小类、合计约三十个独立故事，但没有给出三十个小类的具体名称。

## 分类目的

这是一套服务本游戏世界观、剧本与重复探索的创作分类，不是现实科学的标准分类表。六大类代表世界需要稳定下来的六个方面；小类代表该方面中不同的失效机制。它们不是六种怪物、六种地图主题或六条玩家升级属性。

分类记录在作者和内容配置层。玩家前期只看见故事、遭遇、选择与卡牌，不直接看见分类编码或六类完成度。

## 六大类与三十个小类

### M：物质异常

主管实体的组成、结构和物理表现。核心问题：东西本身出了什么问题？

| 编号 | 正式小类 | 定义 |
| --- | --- | --- |
| M01 | 构成异常 | 组成物体的材料或成分不稳定，或与其应有组成不相容；关注“由什么构成”。 |
| M02 | 结构异常 | 构件之间的组织、结合与排列关系无法稳定；材料本身可以正常，关注“怎样组成一个东西”。 |
| M03 | 物性异常 | 物体对力、热、光、电等作用的响应失常，例如质量、硬度、导热或反射行为；相态、数量及组成问题优先归对应专类。 |
| M04 | 守恒异常 | 物质或能量在封闭过程中的收支无法闭合，持续无来源地产生、减少或耗散；不是藏匿、运输或观察遗漏。 |
| M05 | 相态异常 | 物质的固、液、气等存在状态及相变条件失常；成分不变，关注“以什么状态存在”。 |

### S：空间异常

主管事物所在的位置，以及地点之间的空间关系。核心问题：这里与那里是什么关系？

| 编号 | 正式小类 | 定义 |
| --- | --- | --- |
| S01 | 位置异常 | 一个实体或地点与位置之间的对应失常，如一物多处、位置重合或无法保持定位；不凭空增加独立实体。 |
| S02 | 尺度异常 | 距离、长度、面积或体积的度量失常；连接到的地点可以不变，但远近和大小不稳定。 |
| S03 | 方位异常 | 前后、左右、上下和朝向的对应失常；不是重力改变或主体看错方向。 |
| S04 | 连通异常 | 地点之间的连接关系失常，如门、楼梯或道路通向不应连接的位置；可以保持各处局部的正常尺寸与方位。 |
| S05 | 边界异常 | 内外、包含、分隔及跨界关系失常；关注空间如何被划分，不将墙体材质变软或变透明归入此类。 |

### T：时间异常

主管过程如何随时间推进，以及不同过程如何对应。核心问题：事情在什么时候、以什么节奏发生？

| 编号 | 正式小类 | 定义 |
| --- | --- | --- |
| T01 | 流速异常 | 同一过程经历的时间快慢失常，或局部停滞；不只是钟表损坏。 |
| T02 | 逆行异常 | 一段过程沿自身先后状态反向推进；区别于个别结果提前出现。 |
| T03 | 循环异常 | 一段时间及其相应状态重复进入已发生过的阶段；循环不以道路把人带回原地为依据。 |
| T04 | 连续性异常 | 相邻时刻之间出现缺段、跳跃或无法连接的状态；必须是过程断裂，而不只是记忆丢失。 |
| T05 | 同步异常 | 不同人、地点或过程无法共享一致的时间对应；即使各自流速正常，也不能建立稳定的“同时”或相遇时刻。 |

### L：生命异常

主管生命体的自我维持、发育、繁衍与终止。核心问题：生命如何活着、延续和结束？

| 编号 | 正式小类 | 定义 |
| --- | --- | --- |
| L01 | 代谢异常 | 生命获取、转化、利用和排出维生资源的机制失常。 |
| L02 | 稳态异常 | 身体维持自身、修复损伤、排除异物以及维持组织边界的机制失常；聚焦“维持这个身体”。 |
| L03 | 发育异常 | 生长、成熟、分化与衰老的生命进程失常；外部时间可以正常流逝。 |
| L04 | 繁衍异常 | 生命产生后代、复制生命模板及传递生物性状的机制失常。 |
| L05 | 死亡异常 | 生命活动何时终止、终止是否不可逆，以及死亡后的身体状态失常；死者的记忆或人格出现在他处，未必属于本类。 |

### N：意识异常

主管主体如何体验世界、记住过去、认同自己并自主行动。核心问题：世界如何成为“我的体验”？

| 编号 | 正式小类 | 定义 |
| --- | --- | --- |
| N01 | 感知异常 | 感官输入与主观体验的对应失常，包括看见、听见、感受到不存在或不对应的事物。 |
| N02 | 记忆异常 | 记忆的形成、保存、提取或归属失常；世界本身的历史不必被修改。 |
| N03 | 自我认同异常 | 对“我是谁”“哪具身体属于我”“哪些经历属于我”的认同失常。 |
| N04 | 意志异常 | 意图、决策与行动的自主关系失常，主体无法正常发起或控制自己的行动；不是单纯肌肉损伤。 |
| N05 | 意识边界异常 | 原本独立的主体之间，思想、感觉或体验发生串联、侵入、共享或融合；与个人内部的自我认同分开处理。 |

### C：因果异常

主管事件之间的产生、归属与结果约束。核心问题：为什么这件事会导致那件事？

仅在事件关系本身异常时使用本类。物质、空间、时间、生命、意识的任何异常都会产生后果，不能因此全部标成因果异常。

| 编号 | 正式小类 | 定义 |
| --- | --- | --- |
| C01 | 因果缺失 | 事件的因果链存在断点：结果缺少实际发生的必要原因，或原因无法产生本应产生的直接后果；区别于尚未调查到原因。 |
| C02 | 因果倒置 | 结果先于并指向其原因出现，而周围过程仍正常顺时推进；区别于整个过程的时间逆行。 |
| C03 | 因果转移 | 行为与后果之间仍有明确关联，但后果落在了错误的人、物或事件上，或代价被转嫁。 |
| C04 | 因果闭环 | 一条因果链首尾互为来源，事件、物件或信息没有独立起点；不要求同一段时间反复发生。 |
| C05 | 结果锁定 | 不同选择会引起不同的中间过程，但世界持续改写通路，使其收束到同一被强制的结果；不以偶然巧合或普通高概率事件为证据。 |

## 主类判定规则

1. 按作者确定的根本机制分类，不按玩家第一眼看见的怪象分类。“学校”“鬼魂”“电梯”“分身”都不是小类。
2. 每个正式故事指定一个主小类，可以使用辅助异常表现，但不能让辅助表现另起一套必需解决的核心规则。
3. 以“最终必须修复什么，才能让异常停止”确认主类。如果修正时间同步后所有怪事消失，就以时间同步为主，不因故事包含尸体而归入生命。
4. 同一大类的小类不是现实中彼此完全独立的学科。遇到交叉机制，先用专门条目，再用一般条目；作者必须写出主类判据，不能靠名称强装没有交叉。
5. 一个故事的小类固定，挂机变化的是人物、位置、条件、应对路径及残余问题，而不是每轮把主机制换成另一类。这样反复探索才是在补齐同一类问题的解决样本。

## 容易混淆的边界

| 表象 | 区分方式 |
| --- | --- |
| 一直回到同一层楼 | 时间与事件继续向前，只是楼梯接回原处，归 S04；事件和场景状态一起复位，归 T03。 |
| 某个人突然衰老 | 只改变生命发育机制，归 L03；其所处区域的所有过程经历了更长时间，归 T01。 |
| 不记得刚才发生了什么 | 外部过程与记录连续，仅记忆缺失，归 N02；相关过程确实跨过了一段无法连接的时间，归 T04。 |
| 看见两个同样的人 | 两具独立身体被额外造出，优先查物质或生命；同一个实体映射到两处，归 S01；仅被主体看见的重影，归 N01。表象本身不足以定类。 |
| 铁像水一样流动 | 成分不变而物态失常，归 M05；物态正常但承力响应失常，归 M03；成分实际变成别的材料，归 M01。 |
| 先出现伤口，之后才遭遇事故 | 若整个局部过程都在倒放，归 T02；时间正常前进、只有结果提前，归 C02。 |
| 收到一份没有作者的答案 | 作者只是未找到，不足以认定异常；答案被未来的自己交给过去的自己，归 C04；确实没有任何来源且非循环链，归 C01。 |

## 每个故事进入编写前填写

- 主小类编码与名称。
- 本应稳定的规则是什么。
- 本次异常具体违反哪一条规则。
- 玩家凭什么观察或实验排除普通原因及相邻分类。
- 玩家怎样以低基础能力理解并解除异常。
- 高能力怎样改变应对过程，且仍遵守故事本身的逻辑。
- 首次解决了什么，以及挂机还需要覆盖哪些同类残余问题。

一类一个代表故事，可以形成三十个正式故事的骨架；不要求所有故事都是同一规模，也不把故事标题直接命名为小类名称。当前三个五图测试故事仍是测试内容，不自动占用正式故事名额。
