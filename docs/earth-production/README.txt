无限异常 · 0.11.0 八尺大人／裂口女实装

双击 InfiniteAnomaly.exe，或从项目根目录双击“启动游戏.cmd”。
“启动第一关测试.cmd”直接进入临时测试进度，不覆盖正式存档；可查看街景1—5、重复或重置第一关。
“启动怪谈测试.cmd”直接试玩八尺大人／裂口女，可切换两套异常和五段场景，不覆盖正式存档。
正常游戏从客厅黑门 → 右上“怪谈异境 · 新”选择两套新异常；不用先打完旧300关。
每套含五段连续横向地图，每段5名敌人；队伍自动战斗、向右行进，胜利后可继续／重复／返家。

流程：主菜单 → AVG开场 → 房间探索 → 客厅黑门选择异常 → 开门出战 → 战利品 → 继续下一关 / 重复刷取 / 返回培养。
开场点击画面或空格推进；设置中可跳过、调整音乐/画面和查看记录。
家中点门换房，常驻入口为设置、小队情况。户型图和地点标签已取消。
工作间左侧打印舱进入套装制造与空间升级，右侧为普通装饰；异常记录和支援装置改从客厅黑门进入。

每次胜利掉1件装备。小队/个人培养/结算都可进入装备背包。
每位队员有头部、手部、饰品3个槽；装备带2–3条随机属性，部分召唤独立精灵。
第1关首次胜利固定得到棱镜头盔：选一位战士穿戴，出战即可看到激光精灵。
激光、爆破、治疗精灵只在佩戴者存活时触发；卸下装备取消效果。
原有空间支援装置与装备召唤同时生效。属性装备不改变角色的战斗服和配套武器。

胜利后可直接下一关，也可重复本关。继续挑战会恢复队伍；选择返家才重新分配家中队员位置。
战斗空格暂停；右上角切换1×/2×、召回；召回和失败带回已消灭目标的资源，胜利才掉装备。
F1为调试无敌，默认关闭。地球篇三存档独立于旧版，旧记录自动补齐新字段。

新怪谈的10张背景和10款敌人两种姿势已接入，实际画面待评价。
背景保比例滚动；支持2K／4K视口，但现有背景源高724–727像素，不等于原生2K／4K美术。
新怪物用站姿／攻击图加程序位移、受击和倒地反馈；完整逐帧动作与场景接缝精修仍待制作。
五人仍使用此前测试序列帧，正式战斗套装和强力专属武器视频动作尚未制作。
原300关仍为10主题×30难度，新增301／302为独立怪谈入口，通关不误解锁旧主线。
