# 0.8.0 启动入口修复

2026-10-01，用户反馈双击根目录「启动游戏.cmd」无法打开游戏。

## 原因

实际执行原入口，CMD 在调用「启动地球篇.cmd」前报 `exist` 不是命令，中文脚本名也被错误解析。原根入口只有 LF 换行，修复为 Windows CRLF 后同一路径调用成功；原脚本还硬编码返回成功，掩盖了启动失败。

## 修改

- `启动游戏.cmd`、`启动地球篇.cmd` 统一 UTF-8 无 BOM、CRLF。
- 根入口将参数交给地球篇入口，并保留子入口退出状态。
- 地球篇入口启动前检查发布包 PCK，缺失时显示路径和错误。
- 游戏运行日志固定写到项目 `.local/earth-game.log`，便于后续排查。
- 沿用 0.8.0 发布包和原存档路径，未修改游戏玩法或重新生成素材。

## 验证

- 原入口问题通过真实 CMD 调用复现，记录在 `.local/launcher-fix-080/before-stderr.log`。
- 修复后两个文件 CR/LF 数量分别为 21/21、22/22，没有孤立 LF。
- 正常 Windows 桌面通过修复后的根入口启动，启动器退出码 0，游戏进程正常运行；运行日志无脚本或启动错误。
- 桌面截图 `.local/launcher-fix-080/desktop-menu.png` 实际显示正常客厅游戏界面，确认画面已渲染，不仅检查进程存在。游戏保持打开供用户使用。
- 原文件备份位于 `.local/launcher-fix-080/*.before`；本轮没有上传飞书或 GitHub。
