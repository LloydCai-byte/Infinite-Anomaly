# 八尺大人／裂口女实装 0.11.0

用户要求“做完以后直接实装到游戏里”。本次把 B0001 两套已完成的静态素材接入可玩的 Godot 发行包。默认入口为根目录 `启动游戏.cmd`；直接查看新内容用 `启动怪谈测试.cmd`。

## 进入方式

- 正常进度：客厅黑门 → 右上“怪谈异境 · 新” → 八尺大人或裂口女 → 开门出战。
- 新怪谈编号 301／302，独立于原 300 关主线；完成开场即可挑战，无须先打通主线。新怪谈通关只记录自身战绩，不误解锁旧主线。
- 测试入口直接进入八尺大人，可切换两套、跳转五段、重测；使用临时进度，不写正式存档。
- 第一关测试入口继续有效。0.10.0 及更早发行包保留。

## 实装范围

每套五段背景按原始比例组成连续长地图，摄像机随队伍实际移动。每段五名敌人混编五款设计，最后一段含对应首领，每套共 25 名敌人。战斗持续自动进行，保留暂停、倍速、召回、胜利掉落、继续下一异常、重刷和返家。

30 张原 PNG 逐字节复制到 `assets/earth/anomalies/`：10 背景＋10 待机侧视绿幕＋10 攻击绿幕。运行时通过 Godot shader 去绿；每个姿势独立测量脚底枢轴，使用统一比例，敌人面朝队伍。角色按脚底前后排序，伤害和支援效果绘制在角色上层。完整的素材路径、尺寸及原图 SHA256 见 `source-manifest.json` 和运行时 `catalog.json`。

新怪物用两张画好的姿势配合程序位移、轻微摆动、攻击前移、受击和倒地反馈。五名主角沿用现有临时序列帧。这是已可玩的素材接入版；完整逐帧怪物动作、原生高清源及场景硬接精修仍待制作。现有源图高 724–727 像素，2K／4K 视口成功渲染不等于美术已是原生 2K／4K。

- 新关卡模型 49 项通过。初始五人自然通关八尺大人和裂口女，游戏内分别约 82.5／86.7 秒，均为五段、25 击杀；验证行进距离、战斗中续存、通关存档、装备掉落、重复结算保护、召回与主线隔离。
- 既有回归 1538 项通过，覆盖 AVG、第一关、步幅、存档、素材、装备、房间和界面。旧测试产生的报告重定向到本目录，保留历史报告。
- 从真实 `启动怪谈测试.cmd` 启动 0.11.0 可执行文件，125 项实机检查通过，涵盖黑门鼠标操作、两套全部五段、两种姿势、暂停、自然通关、下一异常、重刷、返家及 2560×1440／3840×2160 GPU 截图。
- 正常根入口 4 项、第一关根入口 9 项通过；均确认实际启动 0.11.0 发行程序。三个入口和地球篇入口保持 UTF-8 无 BOM、CRLF。
- PCK 共 976 条目，在项目外工作目录验证旧关卡、装备、房间与素材依赖通过。测试存档在项目 `.local` 下独立环境，不改正常进度。
