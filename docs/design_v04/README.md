# 设计稿 v0.4 的规则演算

> **仅为历史提案的演算，不再用于新游戏实现。** 当前依据见 [当前设计基线](../当前设计基线.md) 与 [新设计实现大纲](../新设计实现大纲.md)。旧测试通过不代表符合新设计。

这些文件是设计辅助材料，不是 Godot 的运行配置，也没有改动现有游戏逻辑。

- `首章规则样例.json`：首章起始资源、采样路线、掉落池、教学顺序与建议价格。
- `verify_design.py`：穷举缺卡保底状态，核对首章收支、三种训练方向、自动补给及安全停止。
- `规则演算结果.json`：实际运行上述脚本后得到的结果。

使用 Python 3.12 或更新版本，在此目录运行 `python verify_design.py` 即可重算；无第三方依赖。结果只覆盖纸面规则，不能用来声称 Godot 的界面、保存、恢复或完整八章体验已经测试通过。

正文位于上一级目录的 `无限异常_可玩设计稿_v0.4.md`，Word 阅读版为同名 `.docx`。新增规则均为提案；正文列出了与旧版本不同的取舍。
