# 人物与怪物脚底阴影

已发布 **0.40.0-ground-shadows**。根目录的“启动游戏.cmd”与“启动主神空间.cmd”使用新包，流程演示、封面预览同步到新版本。已打开的旧版窗口需要退出后重新启动才能显示此次修改。

[实机对比页](../../art/shadows-20261030/index.html)提供站立、行走、攻击及三种地面环境的前后对比；截图来自实际 0.39 / 0.40 包，使用同一复制存档和固定姿态。新视觉效果仍待用户评价。

## 实际修改

- 旧阴影固定在画布锚点，部分人物的实际脚位偏左，造成黑块偏移。现在读取每帧脚底位置：五位主角、五种现有怪物，共 510 个站立、行走、攻击及受击姿态。
- 两脚分别有较深接触影，外围为较淡的三阶像素投影；单脚伞妖按单脚处理，赤鬼按实际宽脚距处理，轮入道按素材里的小脚处理。抬脚时减弱或取消该脚接触影，倒地时只保留逐渐消失的外围投影。
- 20 张现有场景按地面冷暖配置阴影色。所有地面阴影先于人物绘制，避免其他角色阴影覆盖身体；入场和传送使用角色自身透明度。原传送环继续使用旧绘制函数。
- 原角色图、大小、人物动作、站位、背景、UI、战斗规则及数值保持。当前数据只覆盖已有十种角色；以后新增素材应重新校准脚位。

## 存档与边界

本轮测试均使用独立路径或正常存档副本。开始记录后，正常主神空间主档与 `.bak` 在 21:26:35 发生变化；同时观察到 15:51 启动的 0.38 游戏进程仍存在，具体写入来源未追踪。未回写或回滚这两个文件，其余六个被观察的正常档/历史备份哈希不变。两份当前正常主档副本已成功载入新包。

本轮没有修改其他场景生产队列或写入飞书。完整核验见 delivery-verification.json、package-verification.json、resource-verification.json。
