# 无限异常 · 公寓场景版

已接入按真实住宅照片整理的漫画场景，可在 Godot 中完整游玩《末班电梯》首章。当前主入口为 `scenes/home/main.tscn`；规则采用 2026-09-25 的规划及随后确认的单结局、资源耗尽 Game Over、20 分钟自动存档方案。

## 启动与操作

双击本目录 **启动游戏.cmd**。也可以用本机 Godot 4.7.1 导入 `project.godot`，按 F5 运行。

- 鼠标点门、门洞、电脑、手机及物件。左下角箭头用于转身或返回。
- **P**：拿出 / 收起手机；**Tab**：切换可交互物件提示。
- **Esc**：收起面板；在房间内再次按下可暂停。暂停会停止消耗与探索。
- **Backspace**：返回上一视角；**F11**：切换全屏。

启动脚本复用 `D:\Godot\Godot_v4.7.1-stable_mono_win64` 的现有引擎。此版本是可运行的完整工程，尚未导出独立发行 EXE。

## 怎么玩

1. 起身后点击玄关入户门，阅读门内记忆并出门。画面闪回家中，接替上一个出门的自己。
2. 每次出门会自动接收一段记忆；等待期间可以在家中走动、看手机、提升能力。
3. 首次出门会失败，但仍留下记忆与经验。失败不会立即 Game Over。
4. 手机“成长”可提升战斗、感知或生存。任意一条达到当前门槛即可推进；升级在下一次出门生效。
5. 手机“记忆”可以回看经历，重复记忆可吸收为经验，始终保留第一份。
6. 开启“连续出门”后会自动重试。卡住时利用记忆经验升级。生活储备不足时在手机“补给”补充。
7. 六段经历全部推进后进入唯一结局。生活储备归零才会 Game Over，然后从最后存档继续。

## 当前交付内容

- 七个独立视角：玄关、过厅、厨房、卫生间、卧室、书桌、封闭阳台。卧室和书桌是同一间房的不同朝向。
- 十二张实际游戏 PNG：七张住宅背景、四张异常记忆画面、一张结局背景。
- 场景物件交互、门内记忆预览、三格漫画阅读、手机四页应用、九个成长节点、六份可重复记忆。
- 一章六阶段故事，三种过关叙述、单一结局；补给、自动探索、暂停、音效、音量及减少动效设置。
- 初始存档、20 分钟自动存档、保存退出、校验与三份轮换备份。

本次完成的是带美术的首章可玩版本。规划中的数百事件、完整长篇剧情和更多内容尚未制作；阶段文案与数值是可继续调整的首章配置。没有角色骨骼动画、配音或独立战斗操作系统。

## 存档

新版本使用 Godot 的 `user://home_v2/checkpoint.json`，本机通常对应：

`%APPDATA%\Godot\app_userdata\无限异常\home_v2\checkpoint.json`

同目录 `.bak1`、`.bak2`、`.bak3` 为较旧的轮换备份。

- 每累计游玩 20 分钟自动保存；暂停和开场说明不计时。
- 正常保存退出会额外保存；完成结局也会保存。
- 资源耗尽后的 Game Over 不写入存档，不覆盖可恢复进度。
- 正在接收的记忆保存剩余时间，关闭游戏期间不会消耗生活储备或产生离线奖励。
- 校验失败时暂停并提供恢复备份入口，不直接用空白状态覆盖。
- 旧线框版的 `.local/player_save.json` 不受影响，新旧规则不混用。

| `data/home_content.json` | 首章事件、三条路线文本、技能、资源数值 |

| `scripts/home/phone.gd` | 手机应用与记忆详情 |

| `scripts/home/main.gd` | 场景组装、状态界面、输入和声音 |

运行 `powershell -ExecutionPolicy Bypass -File tools/test.ps1`：规则、界面、跨进程恢复、场景冒烟均使用隔离状态。当前共 137 项断言通过，另完成场景加载与本机鼠标操作检查。

带参数 `-- --home-capture` 运行游戏可保存全部界面截图到 `.local/home-captures/`；`-- --home-smoke` 可无界面检查；`-- --home-test` 禁止写入玩家存档。
