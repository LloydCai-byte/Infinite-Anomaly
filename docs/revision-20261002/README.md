## 试玩路径

双击项目根目录“启动游戏.cmd”进入新版。新建/继续记录 → 完成或跳过 AVG → 点客厅黑门 → 选关 → 开启异境。第一关首次胜利必得棱镜头盔；结算点“整理战利品”，选队员、穿戴，再返回结算继续下一关，能看见精灵发射激光。已有记录也可刷已开放关卡获得装备。

“启动第一关测试.cmd”仍直接进入不写正式存档的临时测试；结算可重复或重置第一关。正式包位于 `builds/InfiniteAnomaly-Earth-0.10.0/`。

## 本轮补齐的数值

每次胜利1件装备；普通55%、精良33.75%、异质11.25%，异质3词条，其余2词条。生命/攻击/防御/攻速/技能强度五类词条，幅度随来源关卡提升。六种基础装备均匀抽取；首次通关第1关固定精良棱镜头盔。召回/失败只有已击败敌人的资源，没有首领装备。

激光每5秒、火种每8秒、水灵每7秒，仅佩戴者存活时工作；换装仅允许战斗外。装备不消耗角色动作版本，不改变战斗服/配套武器外观。这些是可调的首轮落地方案，未声称是用户已指定数值或长期平衡已完成。
