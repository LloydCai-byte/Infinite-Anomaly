## 下载后直接游玩

从 GitHub Release 或飞书“Windows 游戏包与项目参考”下载 InfiniteAnomaly-Reboot-0.4.0-Windows.zip，完整解压后运行 InfiniteAnomaly.exe。保留旁边的 PCK 和 GodotSharp 文件夹。包内 checksums.json 可用于逐文件 SHA-256 校验。完整故事版 1.0 等旧包对应历史设计，不是当前入口。

## 从 GitHub 恢复工程

```powershell
git clone https://github.com/LloydCai-byte/Infinite-Anomaly.git
```

使用 Godot 4.7.1 打开根目录 project.godot，等待资源重新导入。源代码仓库不包含引擎安装包。

## 从飞书独立恢复工程

从飞书项目页下载本项目恢复工具包。需要 Python 3.10+、Git 和已登录的飞书 CLI。工具中的 repository.json 已设置本项目 ID 为 infinite-anomaly；不依赖其他游戏目录。

```powershell
python repository.py list --project infinite-anomaly
python repository.py restore --project infinite-anomaly --version latest --output "D:\Recovered-Infinite-Anomaly"
```

只能恢复到新目录或空目录。看到 status 为 verified 表示清单中每个文件的大小与 SHA-256 均吻合。然后用 Godot 打开恢复后的 project.godot。

## 保存下一版

先提交 Git 并推送 GitHub，再在本项目根目录运行：

```powershell
python tools/feishu-repository/repository.py plan --root . --project infinite-anomaly
python tools/feishu-repository/repository.py push --root . --project infinite-anomaly --message "本次更新说明"
```

飞书文本源码保存 Git 历史，二进制按 SHA-256 分块复用。无变化时不生成新版本。不要同时在两台电脑发布到同一飞书共享文件库。当前未配置定时同步。
