# 重做首章 0.4.0：实现与验收

2026-09-28。依据飞书《开发规划》V2.2（读取 revision 242）及用户“直接制作正式画面和 UI、所有按钮需要素材”的要求制作。此版本完成首章可玩闭环：四人基地 → 选择任务 → 自动战斗 → 回归/召回 → 成长与制造 → 再次挑战。不是整份制作文档的全部内容。

## 启动与工程

- 根目录 `启动游戏.cmd`；发行包 `builds/InfiniteAnomaly-Reboot/`，移动时保留整个目录。
- Godot 入口 `scenes/reboot/main.tscn`；代码 `scripts/reboot/`；资源 `assets/reboot/`。
- 1600×900 设计画布，16:9 保持比例；支持 1280×720 及以上窗口、大字设置。
- 老版本通过 `启动历史收容版.cmd` 或原有独立发行包启动。原脚本、素材、存档不迁入新版本。
- 构建：PowerShell 执行 `tools/build_reboot.ps1`。只打包新版本资源与脚本；文件清单和 SHA256 随发行包保存。

## 已实现内容

| 系统 | 实际行为 |
| --- | --- |
| 开场 | 四人抵达与广播，12 段开场文本；广播结束进入基地 |
| 基地 | 可点击人物与设施；派遣、装备打印、批量训练、配电升级、异常档案 |
| 队员 | 乔越、周霁、林衡、贺维；体质/武器/防具/能力成长和各自交谈 |

| 战斗 | 20 Hz 固定步长自动模拟；跑动、攻击、技能与命中反馈；受击不打断攻击；1×/2× |
| 波次 | 波间只恢复幸存者；倒下的人本次任务保持退出，回基地后四人恢复 |
| 战利品 | 按已完成波次分配奖励；召回只结算已完成部分；完成全任务才增加卡片胜场 |
| 自动策略 | 胜利后返回、重复或下一项；失败停止；胜利后 5 秒倒计时，手动操作可取消 |
| 成长 | T1 上限 5；M03 后支付 500 积分/12 合金升 T2，体质/武器/防具上限 10；能力上限 5 |
| 装备 | 四种职业武器限制；Mk1/Mk2 制造、库存、穿戴、升级、未穿戴装备分解；12 格装备插画 |
| 批量训练 | 30 秒训练，预先付费，可取消退款；与派遣及相关成长操作互斥 |
| 档案 | 三张敌人档案、胜场进度；8 胜金色、25 胜钻色是本构建的可调整试运行参数 |
| 存档 | 3 独立槽；检查点、战斗中继续、完整性校验、备份恢复、删除确认、写盘失败回滚 |
| 设置 | 音量、大字、命中闪烁、后台继续；Esc 关闭/暂停，空格推进对话 |

已制作标题、存档列表、新建/删除确认、开场、基地、任务列表、出发确认、战斗、队员成长、装备、能力、训练、打印、设施、卡片列表/详情、交谈、结算、统计、召回、分解确认、暂停、退出确认、设置和存档恢复等界面及状态。没有把文档中尚未实现的 UI 做成无效按钮。

## 游戏内美术

使用确认过的高清漫画平涂方向：普通成年人、较清晰外轮廓、克制内部线条、统一灰绿/暖灰色板。角色、敌人、背景、装备均实际接入游戏。

| 素材 | 本次实际投入 |
| --- | --- |
| 背景 | 5 张：基地 T1/T2、地铁、公寓、高架桥 |
| 四名队员 | 各 16 姿态：4 待机、4 跑动、4 攻击、2 休息、2 倒下姿态；共 64 格 |
| 敌人与首领 | 3 张、各 16 格；各含普通敌人和首领，合计 48 格 |
| 装备 | 12 件武器/防具插画，随制造配方和装备栏展示 |
| UI | 69 份专用 SVG 资源：4 类按钮×5 状态，面板、HUD、进度条、31 个图标等 |
| 音频 | 10 个原创合成 WAV：环境循环和操作/战斗音效；尚非完整配乐专辑 |

按钮普通、悬停、按下、禁用和焦点均使用 `StyleBoxTexture` 引用专用图形资源；面板使用 NinePatch 图片，进度条使用贴图。没有以默认 Godot 按钮或临时纯色方块替代按钮。标题、图标、布局文字留在引擎中，便于本地化与动态状态。

插画由本轮 imagegen 生成，透明动作图以引擎 AtlasTexture 切帧；没有通过 Python 重绘或修改生成图。UI 为自主编写的 SVG，音效为自主合成。来源与提示词保存在 `art/reboot-production/`。实际游戏截图见同目录 `captures/`。

## 验证证据

| 检查 | 结果与边界 |
| --- | --- |
| 模型 | `tests/reboot/test_model.gd`：46 项通过，无失败 |
| UI | `tests/reboot/test_ui.gd`：4079 项断言通过；主要是逐页按钮素材、焦点、边界和程序信号操作，不等于 4079 个独立真人测试场景 |
| 鼠标命中 | `tests/reboot/test_pointer.gd`：35 项通过；向 Godot 视口注入鼠标事件，通过嵌套按钮命中完成新建、开场、成长、派遣与召回，并验证开场遮罩和禁用按钮；不是操作系统物理鼠标测试 |
| 持久化 | `tests/reboot/test_persistence.gd`：write/read/again 三次独立进程共 12 项通过 |
| 图形 | 1600×900、1280×720 截图检查；大字、装备插画、T2 背景、战斗 HUD 未发现遮挡/越界 |
| 独立发行包 | 使用独立 EXE + PCK 启动验证，资源与脚本加载通过 |

关键检查覆盖：伤害不重置攻击计时；移动期不累计负冷却；波间不复活倒下队员；通关奖励只发一次；召回奖励与页面返回；训练退款；成长上限；装备角色限制；战斗存档恢复后的逐步状态一致；损坏主档后明确恢复备份；槽位隔离；失败停止自动派遣；存档写入失败时撤回消费。

固定配置测试中，1×速度的 M01 初始小队为 50.65 秒，M02 体质/武器/防具 3 级为 71.05 秒，M03 上述 5 级且能力 3 级为 88.40 秒。此为自动模拟测量，尚需真人长时间游玩调整经济与节奏。

测试日志保存在 `.local/reboot-*.log`。沙箱 Godot 的根证书库读取警告属于环境限制；以上游戏为本地离线运行，无对应联网功能。此次检查无 GDScript 解析/运行错误。
