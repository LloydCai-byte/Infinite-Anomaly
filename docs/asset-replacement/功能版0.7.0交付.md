## 已落实

- 主菜单→31节拍开场→返家→任务门→五人自动战斗→胜败或召回结算→培养与换装→再出战的循环可用。
- 开场改为故事图、方形说话人头像、底部文本框、跳动箭头及右上角设置。点击或空格推进；跳过、回到标题等操作收在设置内。
- 七个房间使用现有1920×1080空景；客厅外门打开任务，工作间门/走廊通口/阳台门按现有布局换房。走廊从左到右卧室、卫生间、厨房；镜头身后的门以返回入口处理，不在正面墙捏造新门。
- 户型图上可直接点击房间区域；右侧同步显示各房间的人物分布并可快捷进入。
- 每次结算回家抽取6种合法分布之一，避免连续同一分布。每次五战士各出现一次；轩轩固定在客厅，不含挑衅者。一次返家期间切房不重抽，分布和房间位置入存档。
- 未完成整图时用清楚标示的姓名按钮测试交谈，未粘贴人物立绘。整图文件就位后对应入口可显示整图并使用独立矩形热区。
- 家中常驻设置、户型图、小队情况三个入口。小队按人查看成长、装备、天赋和穿戴；制造进入工作间左侧打印舱，空间升级同入口；右侧收集阵承载任务收录和三种异常支援。
- 设置分音乐、画面、存档三级操作。当前存档可手动保存，三存档及备份恢复继续保留。
- 素材注册表提供237个逻辑编号；菜单、分镜、头像、空景、人物整图、套装展示、动作包、背景、特效、UI与音频有固定替换入口。替换路径放地球篇目录，不覆盖旧版共享素材。
- 新增音效入口与播放连接，现有声效用于攻击、恢复、成长及胜败；没有制作新声音。
