## 2. 我们要实现的游戏

玩家从自己的家进入异常世界，首次通过第一人称整屏单幅场景、观察和选择解决一个故事。该异常随后开放自动重复探索：男主在门外刷，女主留在家中活动，玩家可听音乐、使用番茄钟、从猫眼观看漫画进度，并在收货箱领取每轮送回的物品。收集品分解成不同种类的能力点，玩家提升自身能力，再挑战其他故事。重复探索同时推进异常卡成长，最终服务于创造属于自己的世界。

2026-09-27 补充确认：首次探索不是漫画页，每个镜头是一张铺满画面的完整场景，点击切换镜头与作出选择；不使用分格、拼页、页码或翻漫画的排版。用户提供的电梯整屏图同时作为表现形式与画风参考。漫画轮播只属于后续挂机查看。

这里是男主的探索与女主的陪伴；不再默认继承旧版的小队编成、成员派遣或独立监控房系统。

## 3. 确定的世界观与结局

- 宇宙衰老、文明消亡后，随机涨落仍会生成带有完整初始记忆的存在。人们以为的过去未必真实发生过。此设定是本游戏的虚构世界规则。
- 玩家是罕见的“连续观察者”。死亡是真实的死亡，但其观察与信息连续性延续到极相近的下一次涨落。玩家前期只体验到回到屋子、成长后再挑战，不能开场直接获知真相。
- 女主是超越维度的文明向玩家展示的可理解投影。她协助延续记忆和卡牌，也同时引导许多观察者；玩家不是宇宙唯一的救世主。
- 门通向正在重构的混沌世界；女主筛掉尚不成形的部分，玩家接触的是可理解、可探索的异常。修复异常，就是逐渐补齐自己的世界。
- 卡牌背后是现实切片。反复刷同一异常是在处理相近问题的不同样本，不是把同一个故事原封不动重复发生。
- 六大类别为物质、空间、时间、生命、意识、因果。它们是作者与内容配置层的组织方式，前期不在玩家界面明示分类树、标签或六条进度条。
- 结局是玩家创造自己的世界、获得幸福，与继续寻找宇宙出路的女主分别。不能带回旧版“她来自最后的人类文明”“她独自等过几千个我”等不同身世。
- 按原文最后的具体流程理解：最后一段主线有收束感 → 返回家中没有新故事 → 女主提示把卡刷到金色 → 全金后开放揭秘故事 → 分别并结束。闪光卡是否需要全部完成，不可擅自加作结局条件。

## 4. 确定的玩家体验与规则方向

| 部分 | 当前要求 |
| --- | --- |
| 首次探索 | 第一人称；每个场景是一张完整画面；可选路线、道具与行动；有失败、死亡和成长后再挑战 |
| 对话表现 | 对白出现在说话人物附近，类似漫画；不沿用固定背景加两张立绘对话的默认模板 |
| 自动探索 | 对已解决的异常开放；挂机时不操控男主；每轮结束自动续刷 |
| 家中陪伴 | 女主走动或做日常动作、音乐、番茄钟氛围；不是停在一张结算等待画面 |
| 猫眼 | 点击后，右半屏女主趴猫眼观察，左半屏漫画轮播；观看与否不改变探索是否推进 |
| 远程收货 | 每次刷本结束，物品已送到家中收货箱；不必等男主结束整次派遣再给奖励 |
| 收集与成长 | 多种收集品；不同物品分解后产生不同种类和数量的能力点；不同能力消耗不同点数 |
| 能力性质 | 感知、思维、神经等较抽象、多维的自身能力；不能自动替换成旧版三属性或统一经验值 |
| 刷本动力 | 不同副本产出不同成长资源，因此玩家有选择刷哪一个的理由 |
| 金卡 | 卡牌刷到一定进度变金；还能继续刷，但掉落显著降低 |
| 闪光卡 | 更彻底完成后变成闪光卡；零掉落、关闭进入，女主把玩家引向尚未修复的异常 |
| 两种通关体验 | 观察、选择正确的玩家只需较低的基础数值；长期挂机变强的玩家可用高能力强行解决更多困难 |
| 组合漫画 | 正式重复探索按阶段选择兼容画面，形成不同的经历组合；须维护角色、动作方向与阶段顺序 |

不能把“高数值力大撞飞”缩减成纯文字奖励，后续试作必须验证同一困难在低能力与高能力下的结果差异。

## 5. 保留的美术标准

以用户最后给出的简练全彩漫画参考为最高优先级：清楚墨线、大块本色、朴素而有辨识度的人脸、概括的头发和衣物、少量阴影，避免细腻商业插画或室内效果图的渲染感。保留漫画的力度和普通生活空间的可信度。

2026-09-27 用户确认阶段 1 功能没问题，要求继续，并提供照片作为女主形象参考。阶段 2 保留黑发、细圆框眼镜、松散束发与自然神态，使用浅灰外衫、白色内搭和深色长裤，转换成简练彩色漫画。截图中的界面与文字不纳入设定。日常动作先用阅读、喝茶两张图切换，猫眼另有一张独立图，不宣称已完成连续角色动画。

- 住宅仍以用户自家照片为结构依据：门窗、墙面、开口与房间关系一致，清除杂物，整洁舒服。不把多个房间硬拼成一个不合理空间。

## 6. 本轮测试内容的硬边界

三个临时故事，每个五张完整场景图，合计十五张故事图。它们是测试材料，不承担正式人物塑造、世界观解释或最终剧本的职责。临时故事名称、道具、台词均可替换。

首轮用固定五图序列同时验证手动探索与挂机播放。正式版的大规模漫画变体库以后再补。只有一套五图时，不能声称已经实现“每轮视觉不同”。裁切、滤镜和换台词也不计作新增剧情图。

住宅底图、女主动作用图、收货箱与卡面属于系统素材，单独列制作清单；不偷占十五张故事图名额，也不把它们全部追加为本阶段立即生成任务。

## 7. 尚未定死的部分

原文明确包含试探性表述，以下保留为待试作校准的参数，不用旧设计补答案。

| 项目 | 当前状态与处理 |
| --- | --- |
| 能力维度数量 | “约二十个”是方向，具体名目与作用未齐；先验证少量不同点数与能力，配置可扩展 |
| 金卡等级 | “例如 300 级”不是锁死的正式值；测试环境用短进度验证转金 |
| 闪光条件 | 已明确最终封闭和零掉落；具体由等级、覆盖组合还是两者共同决定，尚需落地 |
| 组合穷尽 | 5×6×4×8=960 是原文示例；有效组合应排除不兼容项，有限素材不能无限不重复 |
| 死亡保留 | 记忆与卡牌由女主传递是明确设定；未结算物品、已投能力点等具体保留边界仍待定 |
| 时间 | 后台失焦是否持续、关闭游戏后是否离线结算、番茄钟与刷本时间关系尚未详定 |
| 经济平衡 | 物品分解配方、消耗曲线、金卡掉率与初始数值尚未定稿 |
| 道具形态 | 分解物件未定，电饭锅只是原文举例；不将它写为正式确定美术 |
| 正式规模 | 六大类、约三十个故事是远期估计；当前仅三个五图测试故事 |
| 终局流程 | 本轮采用文末“全金后揭秘”的具体顺序；不把“全部满级”另解释为强制全闪光 |

这些问题不会阻塞建立第一段可玩的流程。到对应实现阶段采用明示、可改的测试规则，再根据实际体验定稿。
