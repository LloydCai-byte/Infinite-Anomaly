## 核心判断

后续视觉目标是：精确的漫画墨线、可信的日常空间、清楚的物体本色、分层数码上色、大块深黑、局部柔和渐变与材质高光。

“收敛”主要体现为形状、用光、信息密度和镜头组织有控制。不能把它简化成全画面降饱和、灰褐色滤镜、统一纸张颗粒或一律只有两阶平涂。

这两卷存在局部纹理、网点和排线。它们多服务于建筑材质、局部结构和明暗；肌肤与浅色墙面有充分干净区域。后续保留必要纹理，避免全画面同样强度的做旧。

## 线条与人物

- 清晰细墨线为主，轮廓、遮挡、五官和衣褶各有作用，少画无意义的碎线。
- 人体具备明确肩颈、胸腔、手部和肢体结构，姿势有重量，动作可辨。
- 人物仍保留漫画化五官，尤其较大的眼睛；鼻梁、眉骨、眼眶、嘴角与下颌的结构不能被省略成统一的尖脸模板。
- 年龄、体格、脸型、表情应能区分角色，避免所有人共用同一张漂亮脸。
- 头发先确定完整深色轮廓，再用少量分束和方向一致的亮部塑形，不逐根铺满高亮发丝。
- 汗珠、嘴角、瞳孔变化和局部排线承担情绪；日常表情保持克制，突发时允许明显失态。

## 色彩与材质

| 对象 / 环境 | 参考中的可见规律 | 项目使用方式 |
| --- | --- | --- |
| 肤色 | 明亮象牙色、淡桃色或浅粉色，阴影为较深暖色；脸部仍有明确边界 | 保留肤色亮度，避免全员灰黄和大面积脏灰阴影 |
| 室内墙面 | 米白、浅奶黄，通常大块清楚，局部有渐变或受光差别 | 住宅干净舒服，按真实墙面区分亮暗，减少整面砂纸颗粒 |
| 木地板 | 中等暖棕，板缝与透视清楚，有适量纹理 | 保留用户家地板结构，压住过细木纹和强烈油亮反射 |
| 夜间建筑 / 路面 | 靛蓝、蓝紫、蓝灰构成层次，路面可能很亮 | 夜色靠色相与黑白关系建立，不把一切压成看不清的灰黑 |
| 窗口 / 实际灯源 | 小面积浅黄或亮白，位置与建筑逻辑一致 | 用少量局部暖光与冷夜色相衬，保持出口、门窗和物件可读 |
| 黑衣 / 深色装备 | 大片近黑底色，有限灰色或冷色反光；软硬边都有 | 黑色应有分量，高光沿体积走，避免全身发亮或全部哑灰 |
| 金属 | 明确轮廓，冷灰到白的局部渐变，暗部保持深黑 | 材质与普通布料分开，不把所有物件都做成同一种塑料质感 |
| 普通衣物 | 浅紫、薄荷色、红棕、蓝灰等本色能彼此区别 | 饱和度按对象控制，不给所有人统一套灰褐色 |
| 特效 | 亮色局部集中，形状与作用对象清楚；背景和轮廓仍可读 | 先画动作与作用关系，再加必要效果，控制泛光、火星与光雾面积 |

配色应以相应场景的实际参考页为准，不固定一个覆盖全游戏的单一滤镜。这里不提供所谓官方色值；逐张生成时以选定参考图比较色相、明度和面积关系。

## 环境与镜头

- 日常空间是辨识度的重要来源：普通住宅、站台、街道、门窗与楼梯均有可信透视。
- 大墙面和地面允许留白，窗框、栏杆等结构可精细；两者对比使画面既真实又不杂乱。
- 房间尺寸、门窗位置、通路与相机方向沿用用户家照片。画风转换不能改变户型，整洁化约束持续有效。
- 静态镜头可重复使用，以微小姿态、视线和物件变化表现时间，不要求每格都换成夸张构图。
- 全景建立位置，近景给反应，细节格提示原因，大格承担关键动作或结果。连续画面要能追踪动作因果。
- 动作感来自身体重心、透视、接触点、景别和速度线；光效只能辅助。
- 原书阅读方向按原书理解。项目后续漫画继续按已采用的从左到右、从上到下排版，避免同一作品中方向混用。

## 对已有素材的具体调整方向

### 住宅背景

保留当前玄关的门、鞋柜、左侧厨房入口、墙面和地板布局。现图的暖色和安静气氛可延续，但需要减少整体黄褐调、墙面颗粒、细碎木纹与过于柔和的连续晕染。提高米白墙的干净程度，强化门框与关键物件的清晰边界，让阴影更简洁。

### 六页古井战斗样张

已有样张可以保留故事顺序、角色服装身份和人物连续性。后续重绘应优先修正：

1. 灰褐色覆盖过重，各角色的本色差别不足。
2. 肤色偏暗，许多面部与衣物同时叠加了密集纹理。
3. 主角群五官偏统一的精致动画脸，需要加强面部结构与个体差异。
4. 金光、雷光和飞散粒子的存在感偏强；应让动作本体、反应与接触点先成立。
5. 画面频繁强调高潮，后续分镜增加短暂停顿、同机位变化与不安的观察过程。

本研究没有自动重绘这六页。它们是旧版本样张，不继续充当色彩最高标准。

## 三种游戏画面如何共用基准

- 家中场景：横向完整房间视角；结构以实拍为准，美术以本基准为准。交互物件保持场景内呈现。
- 门外 AVG：同一线条与上色系统，以环境图、人物反应和动作插图呈现经历；文字由游戏排版，背景不烘焙按钮或大标题。
- 回家后的记忆漫画：沿用同一造型、动作和线稿语言，按已讨论方案使用黑白；重新安排黑白层次与网点，不能只机械降低彩色图饱和度。

“彩色探索、黑白记忆”的区别来自此前已讨论的表现方案。当前用户指定的这两卷，作为彩色画面的优先参考。

## 检查标准

- 缩小观看时，人物、主要物件、暗部与背景仍有清楚分离。
- 肤色、米白墙和对白留白保持明亮干净，细节不会铺满所有区域。
- 夜景有明确蓝紫层次和局部实际光源。
- 黑衣与金属的反光形状合理，普通墙面不继承同样反光。
- 房屋结构、人物身份和动作前后关系一致。
- 对照对应 PDF 页检查，不再只以“低饱和漫画风”几个字判断是否合格。
