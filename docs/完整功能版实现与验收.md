- 独立存档：`%APPDATA%/Godot/app_userdata/无限异常/containment/slot1.json` 至 `slot3.json`，不覆盖或错误迁移旧规则存档。

## 已实现的完整流程

| 环节 | 实际行为 |
| --- | --- |
| 三十个独立故事实例 | 六大类各五小类；独立 ID、类型名、首次通关、已知线索、当轮线索、访问节点、分支连接、时间点和收集进度。共享五张现有图片与分支模板。 |
| 首次探索 | 单幅整屏场景，人物／物件热点，选项分支、危险分支、对话、现场验证和收容目标选择。 |
| 收容判断 | 先取得证据并验证接缝异常；靠近后方可闭合收容夹。选错目标死亡，当前尝试不允许第二次收容。 |
| 数值支线 | 六项能力开放察觉、推理、反应、逃生、跨越、工具操作路径。界面显示当前值／要求／差值。初始全 1 可通过纯推理路线完成全部三十类。 |
| 死亡与回溯 | 可返回已到达节点或先回家；未访问节点锁定。保留能力、类型收藏、已知线索；恢复节点当时的剧情旗标与收容机会。首次奖励不能重复刷取。 |
| 门的切换 | 未解决故事保留在门后；反锁再解锁选择另一未收容类。已收容类由收藏开启重复收容。男主外出时禁止同时首次探索或换门。 |
| 卡片收集 | 按类型命名，六列分类展示三十个位置，显示数量、金色和闪光。闪光有动态彩色反光。 |
| 挂机与回家 | 男主逐轮收容；每轮推进一个不同样本记录，物品进入收货箱。可要求本轮结束回家；达到闪光自动停止。换房、关猫眼和失焦不重置或停止轮次。 |
| 猫眼 | 左侧当前轮次漫画镜头与样本描述，右侧女主背面对着猫眼；当前秒数与已送回趟数随实际结算更新。 |
| 收货、分解、成长 | 收货箱→背包→工作台分解六类物品→六种能力点→升级六项能力。分解单份／某类全部／全部背包均可；不足时禁止扣款，无负数。 |
| 金与闪 | 一半变金，收益下降；满记录变闪，手动与自动入口关闭，不再产出资源。 |
| 主线终局 | 三十次首次收容后开最终门；未全金受阻，全金假结局，全闪最终揭秘。结局记号保存；假结局后能继续完成闪光。 |
| 家与女主 | 六区域十二点位，房间通路图与场景导航并存；女主按日常轮换房间，卧室阅读／喝茶，其他房间可交流，根据已取得的信息提示，不直接获知未调查的异常。 |
| 家中工具 | 音乐／环境声独立开关和音量；5／25／50 分钟专注，5 分钟休息并循环，提示音；窗口与全屏、交互提示开关。 |
| 正式流程辅助 | 标题、三个记录、新开记录前归档、暂停、玩法说明、保存退出、损坏记录恢复与失败提示。 |

## 本次选用的具体规则与数值

这些是为完整可玩所采用的实现值，可继续调节，未声称来自录音的固定数值。

- 每类总记录 24，首次收容计 1，随后 23 个同类样本；12 变金、24 变闪，每轮 45 秒。
- 普通轮次 3 份主物品加 1 份轮次对应物品；金色轮次仅 1 份主物品。首次成功 3 份主物品。每种物品分解为 3 主点与 1 辅点。
- 感知、思维、神经、生存、体能、协调，初始 1、上限 20。升级费用按当前等级增长。
- 回溯免费，只到曾到达且有检查点的节点；不回到成功结算节点。人物的已知线索与本轮已验证线索分别记录。
- 反锁后解锁，在未首次收容且非当前的类型间随机选择；只剩一个时保持该类型。
- 离线收容默认开启，最多 8 小时，当前类型完成或要求回家时停止，不自动切下一类型。番茄钟只统计游戏运行时长。
- 剧情仍是同一个楼层事件，其他类暂时照用其证据和答案；挂机使用相同五图，不宣称已制作独立异常视觉库。新的房间图、女主立绘、猫眼图已纳入项目，来源见 `art/containment-full/README.md`。

数据入口：`data/containment/catalog.json`、`floor.json`、`balance.json`、`samples.json`。`tools/create_full_content.py` 是本版初始数据生成脚本；修改现有数据后不要盲目重新运行覆盖。

## 保存与一致性

使用校验封包、落盘刷新、临时文件、有效备份和原子替换；操作／奖励／成长即时保存，计时每 5 秒保存。失败时撤回未提交的操作并停止结算。

轮次 ID 与样本 ID 防重复；离线结算连同最新时间一起提交，重复加载不再次派发。主记录损坏尝试备份；主备都损坏时保留原文件并停止载入。重新开始将原始主备文件归档，再创建空白记录。处理了 JSON 数字恢复整数域的问题。
