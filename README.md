# 无限异常 · 完整故事版 1.0

以你的住宅为原型的异常探索游戏。门内是整洁的日常居所，门外是不断重复的异常空间。观察、行动、带回记忆，训练能力，最终让这栋楼遵守自己的规则。

## 直接游玩

双击根目录 **启动游戏.cmd**，或打开 **builds/InfiniteAnomaly-1.0/InfiniteAnomaly.exe**。

发行目录包含运行程序、游戏 PCK 和 GodotSharp；移动时保留整个文件夹。无需打开 Godot 编辑器。目标为 Windows 10/11 64 位、OpenGL 3.3，已在本机 RTX 5060 环境验证。

- 鼠标点击房间中的门、冰箱、床、电脑、手机和漫画册。
- **Tab** 显示交互位置，**P** 打开手机，**Esc** 关闭面板或暂停。
- **Space** 立即显示当前叙述，**1/2/3** 选择行动，**F11** 切换全屏。
- 左下角箭头返回上一视角。窗口失焦自动暂停。

## 当前完整内容

- **三章九个异常场景，二十七处线索，一个剧情结局。**
- 七个独立住宅视角，彩色门外探索，十八格黑白记忆漫画。
- 感知、战斗、生存三条成长路线，每段故事都有对应的成败叙述。
- 重复探索可自动运行；新内容停下等你接手，等待时不消耗资源。
- 经验、补给、成长、失败反馈、记忆收集、监控、暂停、声音设置和完整存档流程。
- 二十一张为本游戏生成的美术图，九个原创合成音频。

这是可从开场玩到结局的有限篇幅版本，采用点击探索与能力判定。当前边界为三章九事件；远期更多副本、数百事件和即时动作战斗不在本次完成内容内。

## 从哪里开始

玄关点门，选择路线后转动把手。门外至少观察两处线索，再作出行动。手机可用经验训练能力；卡住后重走已完成路线。电脑可切换自动探索的行动方向及循环方式。冰箱或手机可补充食物。卧室白桌上的漫画册保存经历。

不需要故意反复失败刷级：首次发现和成功探索给经验，重复失败不重复发奖励。专注任一条能力均可通关。

## 存档

当前版使用 `%APPDATA%\Godot\app_userdata\无限异常\campaign_v3\checkpoint.json`。

初始记录、累计 20 分钟有效游玩自动保存、床边记录、保存退出及结局都会写入存档。采用校验与三个轮换备份，无效主存档会尝试有效备份。食物耗尽后直接 Game Over，死亡状态不会覆盖可恢复的记录。

暂停、未知内容等待、结算及结局期间不消耗资源。关闭期间无离线消耗或离线奖励。旧 `home_v2` 及线框版存档保留，规则不混用。
