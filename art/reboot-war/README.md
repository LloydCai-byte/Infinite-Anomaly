# 后续任务与星际战争资源

这是0.5.0实际使用的资源登记与Godot运行截图。漫画平涂方向沿用用户选择；图集包含实际动作，PNG保存在 `assets/reboot/` 各分类目录。

- `generated-sources.json`：36项生产资源及生成来源/提示词记录；来源路径仅供本机追溯，发行运行不依赖该路径。
- `registration.json`：图集区域与透明度检查结果。
- `captures/`：同一套新界面的1600×900与1280×720运行截图；文件名带 `large` 为大字模式。

`tools/register_war_art.py` 根据透明间隔登记完整角色边界，只写清单，不编辑PNG。训练背景7、星区12、轨道1、房间等级2、敌人8套、四兵种4套、进阶装备1套、运输房间1套。敌人16帧/套，兵种16帧/套，运输3帧，装备12格。

其中 `15-ending` 与 `18-final-memorial` 取自完整战争自动推演的实际完成存档。其他界面截图使用用于检查布局的状态；截图本身不是通关证明，通关记录见 `docs/reboot-war/qa/`。
