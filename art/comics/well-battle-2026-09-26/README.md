## 必须延续的剧情事实

1. 贞子浑身湿透、长发遮脸，从电视画面快速爬出。张子陵催促众人启用事先准备的护身灵符。
2. 贞子高速穿过人群，掌击朱灵焰。金刚护体挡住伤害，但冲击仍把她拍飞。
3. 朱灵焰的护符燃烧，她启用雷遁查克拉模式与转动的红色瞳术。
4. 赵樱空以诡异步法与残影，从背后用双刃攻击，却被无形力量弹开；她翻身落地继续上前。
5. 郑吒开启基因锁冲拳。戒指干扰贞子的无形能力，拳上涌现红炎。
6. 张子陵拔掉电视插座，电视仍亮；尝试用手腕储物空间收走电视也失败。
7. 李帅西背着大剑，把佛骨舍利放到电视上。电视发出凄厉声音，原来屋内阳光消失。
8. 大部分人被拉到电视世界古井附近；原来攻击朱灵焰的贞子突然消失。
9. 井中接连爬出惨白的贞子分体，快速扑向众人。灵力弹药可以打散分体，但井口不断补充，形势形成持续压力。
10. 铭烟薇发现李帅西与张子陵没有出现在队伍中。楚轩判断不能再留手，要求取出准备好的道具。
11. 众人准备黑狗血、童子尿和朱砂等对付诅咒的材料；詹岚与朱灵焰招呼影分身搬运木桶接近井口。
12. 齐腾一通过腕表储物空间取出十几口棺材、桃木剑、法坛与道袍，戴八卦镜、点香、取符并念咒。
13. 棺盖打开，形态不同的僵尸站起，最初紧闭双眼。齐腾一以指尖血绘符，使符纸浮空并落在僵尸额头。
14. 咒符金光闪过，僵尸睁眼，受他指挥冲向鬼群。他又继续施符攻击，为队伍挡住一面压力、争得喘息。
15. 叙事切回原先的电视房：张子陵、李帅西仍在围攻贞子，对其他人的消失同样感到惊疑。截图到这里截止，没有全胜结局。

## 六页分镜

1. 电视突袭：静室 → 手伸出屏幕 → 启符警告 → 护盾成形 → 朱灵焰被击飞。
2. 近身交锋：雷光恢复 → 赵樱空突袭 → 无形力弹开 → 郑吒银戒干扰 → 红炎拳。
3. 空间突变：拔电无效 → 收取失败 → 舍利落在电视上 → 白光吞没房间 → 古井世界。
4. 无穷分体：井口爬出分体 → 灵力弹扫射 → 发现缺员 → 拿出道具 → 棺材落地。
5. 控尸：起坛穿袍 → 棺盖打开 → 指血绘符 → 符纸飞向额头 → 尸群睁眼。
6. 两处战场：尸群挡住鬼潮 → 队伍获得喘息 → 井仍涌出分体 → 切回原房两人面对贞子。

每页从左到右、从上到下阅读；对白重新压缩，不把小说段落直接铺满画面。末页停在原片段的双战场悬念上。
