折臂通勤者

他总是赶着上车，却从来不看时刻表。风衣口袋里塞着过期月票，公文包的锁已经锈死。每当站台灯熄灭一盏，他折起的手臂就会多出一个拐角，像是把走不完的通勤路藏进了袖子。队员第一次靠近时，他依旧闭着眼；只有公文包先一步伸了过来。

折臂抱包、肩部后收 → 折臂拉开，公文包前砸 → 收包归胸，恢复闭目待机

伸钳检票员

最后一班车离站后，他还在检查不存在的乘客。帽檐下没有可辨认的表情，腰边挂的车票都是空白的。曾经用来剪票的小钳子与袖管长在了一起，一节接一节伸向站台尽头。他不会询问目的地，发现靠近的身影便重复同一个检票动作。

钳臂屈起，白手仍持票 → 矩形臂节伸出，钳口合拢 → 钳臂逐节缩回

枕木匍行兽

货运侧台上有一垛枕木，无论搬走多少根，第二天总会回到原来的高度。最下面的铁箍会在夜里折成腿，两只苍白的手从木缝伸出，慢慢摸索地面。木头仍带着雨水和机油的味道，移动时能听见装卸货物般的闷响，却始终看不见搬运的人。

铁足压低，白手缩进木缝 → 铁足推进，双手前伸抓击 → 白手缩回，枕木躯干落稳

鼓腹祭客

远处的祭典早已散场，鼓声仍沿着铁道传来。这位祭客把鼓背进了身体，红绳勒住藏蓝衣袍，只留一张小小的空白面孔。它像是记得一段没有结尾的乐曲，遇到活人也不停演奏。木槌落下时，鼓皮上的空气会被敲出一道清楚的弧线。

两槌抬起，鼓腹微后仰 → 双槌击鼓，气浪向前 → 木槌回弹，细腿站稳

长影引路人

他一直在隧道旁等人，衣服旧，笑容却很亲切。他会摊开手，示意疲惫的旅客往这边走。可灯照在身后时，他的影子仍向来人伸过去；影子的末端也不是鞋，而是张开的手掌。那双过长的腿让他几步就能走完一段站台，脸上的笑从未变过。

微笑伸手，影手聚拢 → 弯膝前倾，影手向前拍 → 影子退回鞋底，恢复邀请姿势

反肘巡田人

村口常能见到他低头量田，帽沿压得很低，袖口永远卷到同一个位置。没人说得清他是哪户的农人。远望时他的动作十分熟练，走近后才发现，那只拿竹尺的手是从肩膀背后绕过来的。他不回答招呼，只把面前的人也当成需要丈量的田界。

竹尺收于身侧、反肘抬起 → 肩背扭转，竹尺向前横扫 → 尺尖落低，反肘归肩后

风袋长颈客

这是田边用了很多年的驱鸟风袋，红色已经晒成淡褐，金属口沿也掉了漆。某个没有风的午后，它自行撑满空气，竹杆从地里拔出了两条腿。雨披下面的小手始终紧握着自己，像在努力稳住一个过重的脑袋；无论风往哪边吹，袋口都朝着靠近的人。

袋颈后弯，口沿抬高 → 软颈前甩，圆口沿撞击 → 袋颈回卷，竹节腿站稳

稻束背夫

晒谷棚旁的搬运工从不卸下背上的稻束。干草比他的身体宽得多，两头垂下的草结远看像松散绳头，近看却是有五根指头的巨手。他自己的手一直抓着肩带，沉默地往前走。四只旧布鞋踩出的脚步不在同一节拍上，但每一步都很稳。

四足分开，草绳手后摆 → 稻束旋转，巨草手前拍 → 草手垂下，四足归位

水渠折扇虫

村里的灌渠停水后，闸门却还在每天开合。脱落的铁片一层压着一层，围住一块白瓷刻度盘，管道在下面长成短足。它平时伏在泥边，像一件被遗忘的农具；受惊时整面闸片忽然张开，露出扇贝一样的轮廓。刻度盘上的弧线始终像一只闭着的眼。

短足压低，闸片合拢 → 背壳扇开，前足撞击 → 闸片回叠，软管尾收卷

田间白折影

盛夏的田地尽头有一条白色轮廓，看起来像人，也像挂在空中的布。稻穗已经静止，它仍在反复弯折：脖子、腰和膝盖各自朝向不同方向。队员逼近后，没有看见清楚的脸，只看见一道又一道冷白折面。它的长臂展开时，整个身体像一条被拉直的折痕。

全身S形反向压折 → 腰膝展开，布条长臂鞭扫 → 各关节重新反折，回到扭动待机
