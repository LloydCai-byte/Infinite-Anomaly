# 完整故事版美术素材

2026-09-26，项目正式入口使用 `assets/v3/`。

本次使用图像生成工具制作了 21 张最终美术图；包含两次针对浴室地砖和登记室文字的修订，共 23 条生成记录。精确提示词、输入参考、原生输出位置记录在 `prompts.json`。参考漫画只用于画风研究，原始漫画和住宅照片不进入发行包。

## 视觉约束

- 家庭空间以用户住宅照片及已有结构图为原型。保持门、窗、墙角、主要家具和连接关系；清理杂物。
- 细黑线、准确透视、干净固有色；米白墙、暖棕木地板、灰窗帘，夜景采用蓝紫与暖黄灯光。
- 宽幅彩色场景用于实际探索；黑白漫画用于带回家中的记忆。不用统一灰褐滤镜、满屏噪点或金属科幻大厅。
- 新绘制原创主人公及巡层员，不复制参考漫画人物和黑球。
- 所有背景不带界面文字，文字和交互由 Godot 绘制。
